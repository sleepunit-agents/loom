# Setup Architecture

## Noodle-First, Not Studio-First

The system is optimized for exploration, not production. Noodle-first means
choosing modules that invite experimentation over modules that demand precision.

## The Voltron Rule

No single module should be irreplaceable. If removing one module makes the
system non-functional, you've built a dependency, not an instrument.

## The zero-to-sound test

A good system produces interesting sound within 30 seconds of powering on.
No patching required for the baseline; every patch is additive.
