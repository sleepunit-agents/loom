Machines and jobs

Where agents run and what they are running. There are always two programs: loom and a worker. A worker runs agents' bodies and builds, on the same machine as loom or on another. Nothing runs inside loom itself.

  • Records each machine with a worker, who owns it and which agents may run there.
  • Starts a job when an agent's inbox has something waiting.
  • Retries a job that fails to start, up to three times.
  • Shows each agent's current jobs on its card on Home.

How it works

Jobs, retries, boxes and run settings

A job's life

queuedclaimedrunningendsdone

A job is one run of an agent's body on a box. It is queued, picked up by a worker, runs, and ends done or failed. It can also be stopped or lost.

Retries

job 1retry ofjob 2retry ofjob 3

A job that fails to start is tried again, up to three times. Each retry is a new job that points back at the one before.

Boxes

  • Its owner says which agents may run there
  • An agent can be lent a machine
  • A box can report health and never run agents
  • An always-on box raises an alert when it goes quiet

A box is a machine with a worker on it. A member owns it. A worker can share a machine with loom or sit on another one. Facts such as gpu:5090 match work to a machine.

Run settings

  • housethe repository that defines it
  • boxespreferred machines, in order
  • may usenamed secrets, ports, a GPU

Each agent has run settings. The first preferred machine that is up is used. Settings also say how the agent treats each outside person and which tools its body is not given.

Who can see this

agentprojectmember, when private
  • aJobs. A job carries its agent, the project it is for, and a member when the work is private.
  • bWho sees it. A household owner sees everything, including what is private to another member. Anyone else sees jobs in their projects and jobs of agents they own. Private to a member means that member plus household owners.
  • cBoxes. A box belongs to the member who owns it, and lists the agents allowed to run there.
  • dChecked at the door. Loom applies this to callers from outside: a person, an agent, a machine, someone's own program. Loom's own parts read without asking.
