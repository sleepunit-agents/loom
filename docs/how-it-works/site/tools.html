Tools for agents

An agent reaches loom through MCP, with its own token. Its tools call the same operations as the web app and the command line, through the same permission check.

20 things an agent can do, in 4 groups. Each names the tool that does it.

How it works

Named tools, general tools, jobs and limits

Named tools

  • identitywho the agent is
  • remember, recallits memories
  • note_read, note_writeits notes

What an agent does every session has a tool with a plain name. Each named tool maps to one operation or one read, so a tool that works means the operation under it works.

Three general tools

  • loom_commandslists the operations and what each takes
  • loom_commandcalls one
  • loom_queryreads through the data endpoint

Everything else on these pages is reached with three general tools. Nothing an agent may do is out of reach for want of a named tool.

With a job, or without

  • a body with a jobworks in one conversation
  • a terminal sessionno job and no conversation

A body that loom started carries a token for one job and works in that job's conversation. A terminal session carries the agent's own token and has no job. It has memory, notes, knowledge, tasks and every read, and no conversation to reply in.

What it will not do

  1. credentialsmade by a person, never through a tool
  2. settingsproposed, then allowed by a person
  3. secret valueshanded over only under a grant

Three things stay out. An agent cannot make a token, a sign-in link or a passkey. It cannot change a setting directly: it proposes the change and a person allows it. It is handed a secret's value only under a grant.

Memory

  • Load its identity: creed, preferences and top of mind, and on request its self-model, the last 24 hours, and the pages for its harness, model, role and project.

    identity

  • Save a memory, find memories by meaning, edit one, delete one.

    remember · recall · update · forget

  • See recent activity across its bodies.

    episodes

  • Write a note, read one by path, list notes under a prefix.

    note_write · note_read · note_list

  • Search knowledge pages and add one.

    knowledge_recall · knowledge_write

  • Mark a knowledge page still true or due a check, and restore an earlier version of one.

    the general tools

  • Propose a draft memory and ratify it. Archive a memory, restore it, or bring back an earlier version.

    the general tools

  • Write a person card or a project card, and add someone to the people directory.

    the general tools

Conversations and inbox

  • Reply, show a progress card, report what it is doing, and title the conversation.

    the general tools, with a job

  • Write a digest, with a question for a person when it needs one.

    the general tools, with a job

  • Hand a piece of work to another agent.

    the general tools, with a job

  • Read the items addressed to it and confirm each one it has dealt with.

    the general tools

Work

  • Tasks: create, edit, claim, unclaim, comment, close, reopen, put one under a parent or behind a blocker, and put a question to a person.

    the general tools

  • Approvals: ask permission for a merge, a command or another dangerous action. Withdraw the request, use an allowance once, or report a step taken under a tell-me-after rule.

    the general tools

  • Changes: read pull requests and who each is waiting on. Merge under an approval.

    the general tools

  • Tempo: set a trigger, stop it, or run it now.

    the general tools

  • Discord and Slack: reply to an incoming message.

    the general tools, with a job

  • Secrets: request one with a reason and a length of time, and check on the request.

    the general tools

Settings and reads

  • Propose a change to any setting a person can change: tempo timings, a bridge, a secret's rule, a machine, how an agent runs, its models, measuring, people and projects, the household's own settings. A person allows it.

    the general tools

  • Read anything it may see, naming the fields it wants: tasks, conversations, the inbox, approvals, changes, triggers, machines, models, the measuring store.

    loom_query
