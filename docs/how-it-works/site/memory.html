Memory

What an agent remembers and knows. Memories, notes, knowledge pages, people cards and project cards. Memories are the one kind of data loom treats as precious. Notes come second.

  • Keeps each agent's memories in that agent's own files.
  • Recalls by meaning, and keeps what is used most at the top of mind.
  • Keeps notes: longer working documents, by path, each with a lifespan.
  • Keeps knowledge pages with where each fact came from, and re-checks them.
  • Shows what happened each day in Activity.

How it works

What is kept, top of mind, notes, changes and knowledge

What an agent keeps

  • memoriesin seven categories
  • knowledge pagesfacts, with their sources
  • people cardswhat it knows about a person
  • project cardsa project's card
  • notesworking documents, kept by path
  • identityits creed, preferences and self-model

Memories, notes, people cards, project cards and identity live in each agent's own folder. Knowledge pages and the people directory are shared by the household. Identity also holds a page for each harness, model, role and project the agent works in, loaded when asked for, and a summary of what its other bodies did in the last 24 hours.

Top of mind

  • hotused or written lately
  • warmcooling
  • coolnot used in a while

Each memory has a temperature. Writing it heats it fully, recalling it adds heat, and it cools with time: an episode within a day, what an agent knows about a person over months. The hottest fill the agent's top of mind. Recall finds memories by meaning. A memory can be given a time to live, and is archived when that runs out. A lesson the agent was taught can be confirmed or contradicted later, which raises or lowers how much it is trusted.

Notes

  • keepuntil removed
  • while60 days after its last change
  • short14 days after its last change

A memory is a fact. A note is a document: a handoff, a review, a pile of evidence. A note is kept by path, written whole, and read by asking for it by name. It is never recalled by meaning and never fills the top of mind. A memory usually says a note exists and where. Each note has a lifespan, and a change restarts it.

Changing a memory

  1. proposea draft recall cannot see
  2. ratifythe draft becomes real
  3. archiveset aside, can be restored
  4. forgetdeleted, and the deletion recorded

A change saves the earlier version first. Loom keeps the newest ten versions of each memory, knowledge page and person card, and any of them can be restored.

Knowledge

  • Fresh
  • Getting old
  • Due a check

A knowledge page is a fact about the world that says where it came from. Without a source it stays provisional. Pages are re-checked every 30 days.

Who can see this

agent
  • aMemories, notes and cards. The agent itself, the agent's owners, and household owners. Being on a project together does not open an agent's memories or notes.
  • bKnowledge. Knowledge pages are shared by the household. Household owners and household agents can read and write them, including agents in terminal sessions without a job. Non-owner members cannot.
  • cPrecious. Agents' memories are the only data loom treats as precious.
  • dNotes come second. Every backup and every move to a new home carries all of an agent's notes, whatever their lifespan. They are not on a par with memories: a note still ends when its lifespan does.

Data model

Memory is not in loom's database. It lives in files, and it is the one kind of data loom treats as precious.

  • each agent's folderIts memories and their history, drafts awaiting ratification, its notes and their earlier versions, people cards, project cards, and its identity files.
  • shared by the householdKnowledge pages and the people directory.
