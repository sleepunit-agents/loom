Approvals

Permission from a person for an agent to do one specific thing. An approval covers one of four things: a merge, running a command on a machine, changing a setting, or another dangerous action.

  • Shows each request with what happens if you allow it and if you deny it.
  • Lets a person allow or deny, with the exact change in front of them.
  • Shows a card inline in chat when a setting change or a dangerous action is asked for there.
  • Holds standing rules, and keeps a permanent record of every request, answer and use.

How it works

Requests, rules, chat and the record

One request, one use

pendingallowalloweduseused

An agent files what it wants to do, to exactly what, and why. An allowance lasts a set number of minutes and is spent once. A request can also be denied, withdrawn or expire.

Rules

  • Ask meask first
  • Tell me afterdo it and report
  • Just do itno question

A rule answers one kind of request the same way every time, for a scope such as certain repositories or commands. A rule that names a person is a grant to that person. Only the household owner edits rules.

Asked for in chat

Change a settingWake jonathan's inbox every minuteBefore: the default. After: 60 seconds.

When a person asks an agent in chat to change a setting or do something dangerous, the agent proposes it. Loom shows an approval card inline, with exactly what will change, before and after. On Allow loom makes the change itself and records it. Ordinary work needs no card.

The record

  1. requestart asks to merge
  2. allowjonathan allows
  3. useart merges

Loom keeps every request, answer and use in a record that is never edited. Steps an agent took under a tell-me-after rule are listed as reported steps.

Who can see this

agentprojectmember, when private
  • aThree labels. An approval carries the agent asking, the project it concerns, and a member when it is private to them.
  • bWho sees it. A household owner sees everything, including what is private to another member. Anyone else sees approvals in their projects and approvals of agents they own. Private to a member means that member plus household owners.
  • cChecked at the door. Loom applies this to callers from outside: a person, an agent, a machine, someone's own program. Loom's own parts read without asking.
